# 04 · s1-site-map — "Three pages, one head, one nav, one footer"

**Deck:** Part 1 · **Indicator:** Part 1, not RPS · **Time:** 3 min
**Folder:** README + `start/` only — no live edit. `start/` = `/stages/stage-5b-semantic/`.

## Open when the slide appears
`start/index.html`, `start/location.html` and `start/book.html` in three browser tabs.

## Typed live
Nothing.

## Room sees
You click through the nav: Menu → Location → Book a Table and back. Every page has the same
header, nav and footer. That is the whole demonstration.

## What to say
- Name the cost honestly: the header, nav and footer are copied three times. Change the
  phone number and you edit three files; on a 40-page site, forty.
- "Why not include a file?" — plain HTML cannot. Components are Week 7; a CMS is Week 9.
- Bridge to Part 2: "the header is copied three times; the STYLE will not be."

## Fault to expect
None on this slide. If a student's own nav goes to a missing page, the file name and the
href differ — case counts, and it will matter again in Part 6.
