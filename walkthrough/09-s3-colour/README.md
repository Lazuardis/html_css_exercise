## Room sees
Five lines in red, in the order of the slide's table: `red`, `rgb(255, 0, 0)`,
`rgba(255, 0, 0, 0.8)`, `#FF0000`, `hsl(0, 100%, 50%)`. Four are identical; the RGBA line
is slightly lighter — the alpha of 0.8 lets the near-white background show through. That
is what the fourth row of the table means.
Below them, a teal band reading `#064E4F`, with the three pairs spelled out.

## The one skill to insist on
Read a hex code as three pairs: `06` red, `4E` green, `4F` blue. Do the arithmetic once:
F is 15, so FF is 15 × 16 + 15 = 255. Brand guides give colours as hex.

## Fault to expect
"Which one should I use?" — hex for anything from a brand guide, rgba when you need
transparency, names for a quick test. The slide says so; do not add more.

The values follow the slide (RGBA at 0.8), so the page matches the projector.
