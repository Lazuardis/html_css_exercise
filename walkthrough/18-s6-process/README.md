# 18 · s6-process — "Five steps in the browser, no terminal, no git"

**Deck:** Part 6 · **Indicator:** Part 6, not RPS, not examinable · **Time:** 4 min
**Folder:** README + `start/` only — no file edit. `start/` = `/deploy/` (stage 6 final).

## Open when the slide appears
github.com, signed in to your own account, on the projector. `start/` open in File Explorer.

## Done live — browser only, in this order, naming each step
1. **Sign in.** Read your username aloud, exactly as GitHub shows it.
2. **New repository.** + → New repository. Name `username.github.io` — lowercase, your
   username, nothing else. Public. Create repository.
3. **Upload the folder.** Add file → Upload files. Drag in the *files* from `start/` —
   `index.html`, `location.html`, `book.html`, `style.css`, `falafel.jpeg`, `salad.jpeg` —
   not the folder itself. Commit changes.
4. **Check Pages.** Settings → Pages. Source: Deploy from a branch · `main` · `/ (root)`.
   Save if it is not already set.
5. **Wait, then visit.** Actions tab: wait for the green tick (one to ten minutes). Open
   `https://username.github.io`. Send the link to a phone.

## Room sees
The Little Lemon site at a public address.

## Fault to expect
The repository name. A capital letter, a typo, or `little-lemon` instead of the username
gives no site at `username.github.io`. Do not re-upload while waiting — it restarts the clock.
