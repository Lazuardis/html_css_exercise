# 00 · hook — "What, exactly, is the difference?"

**Deck:** Opening · **Indicator:** none (sets up Parts 1–6) · **Time:** 2 min
**Folder:** README + `start/` only — no live edit. `start/` = `/stages/stage-4/`.

## Open when the slide appears
- Browser tab 1: `start/index.html` (double-click it).
- Browser tab 2: any real restaurant's website, chosen before class.
- Board or whiteboard, two empty columns, no labels yet.

## Typed live
Nothing.

## Room sees
The Week 3 page next to a real site. Students name three concrete differences; you
write them in the two columns without labelling them.

## What to draw out
- Column 1 becomes ORGANISATION (menu bar, header with the name, footer with the address,
  more than one page) — Part 1.
- Column 2 becomes APPEARANCE (colours, fonts, spacing) — Parts 2–5.
- If someone says "it has a real address, mine is a file on my laptop", that is Part 6.
- Leave the board up; walkthrough 01 points back at column 1.

## Fault to expect
"It looks better" as an answer. Ask for three *concrete* things.
